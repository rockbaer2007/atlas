# Tabbed Card V2 Visual Editor

Standalone visual editor demo for the Home Assistant `custom:tabbed-card-v2` configuration.

Run locally:

```powershell
node examples/tabbed-card-v2/server.mjs
```

Open:

```text
http://127.0.0.1:4176/
```

The editor is intentionally independent from ATLAS internals. It generates a plain Home Assistant Lovelace YAML card using the `custom:tabbed-card-v2` schema.
