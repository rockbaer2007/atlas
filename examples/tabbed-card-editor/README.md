# Tabbed Card Visual Editor

Standalone visual editor demo for the Home Assistant `custom:tabbed-card` configuration.

Run locally:

```powershell
node examples/tabbed-card-editor/server.mjs
```

Open:

```text
http://127.0.0.1:4176/
```

The editor is intentionally independent from ATLAS internals. It generates a plain Home Assistant Lovelace YAML card using the `custom:tabbed-card` schema.
