# Roadmap

The canonical ATLAS roadmap lives at the repository root in `ROADMAP.md`.

For the VitePress documentation site, the current roadmap focus is summarized
here so navigation stays inside the docs tree.

## Current Focus

ATLAS is moving from G2.5 stabilization into product-facing integration work.
The active product scenario is Home Assistant:

- themed ATLAS status panels
- entity selection and live entity loading
- Home Assistant card export and import
- Mushroom and Bubble Card target selection
- Lovelace dependency checks
- Atlas card packages as a bridge toward future HACS workflows
