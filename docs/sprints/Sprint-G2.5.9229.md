# Sprint G2.5.9229 - Custom Card Resource Mapping

## Ergebnis

- Added local mapping for registered but unknown Lovelace resources in the Card Editor palette.
- Mapped resources can now become draggable Expert palette cards with a user-provided `custom:*` card type.
- Preserved mapped custom card type and resource URL through Expert fields, nested containers and exports.
- Included mapped custom-card resource paths in the Card Editor frontend resource plan.
- Bumped the Home Assistant Card Editor to `0.2.0-alpha.63` and the Home Assistant App/Add-on package to `0.1.164`.
